REFERENCE / 所有権

型から「渡すもの」を読む

所有権の移動と、所有者を残したままアクセスする借用を分けて読む。

今回のコードで注目する型
型読むときの手掛かり
String値として渡すと所有権が移る。元の束縛からはその値を使えなくなる。
&mut selfメソッドを呼ぶ対象を可変で借りる。対象そのものの所有権を引き渡す形ではない。
Option<String>Some なら所有する本文が入り、None なら本文がない。expect は Some の中身を取り出し、None ならパニックする。

「値を渡すと必ずムーブする」という一般則ではない。例えば整数などの Copy 型はコピーされる。今回は String を追う。

コードを追うときの三つの問い

  1. 今、この値を所有しているのはどの変数、またはどのデータ構造か？
  2. 次の呼び出しは、値を渡すのか、参照を渡すのか？
  3. 呼び出し後に、元の変数と戻り値のどちらから使えるか？
